# Project Statement

## 1. Problem Statement

In many event-based systems, it can be difficult to notice unusual or inconsistent patterns when events are recorded over time. This project provides a simple way to record events related to people and check them for predefined unusual patterns, referred to as "reality glitches".

The application allows the user to enter event information such as the person involved, event type, location, and time. The recorded information is then checked using predefined rules and the results can be viewed and saved as a report.

## 2. Scope of the Project

The project focuses on a Java-based console application for recording and analyzing event information.

The current scope includes:

* Adding and viewing people
* Recording and viewing events
* Checking events using predefined rules
* Detecting and displaying glitches
* Saving glitch reports to a file
* Simulating event processing using threads
* Handling invalid user input

The project is currently designed for a local console environment and does not include database or online functionality.

## 3. Target Users

The project is mainly intended for:

* Students learning Java programming
* Users who want to experiment with event-based anomaly detection
* Developers interested in a simple Java-based monitoring system
* Evaluators who want to understand the use of Java concepts in a complete application

## 4. High-Level Features

* **Person Management:** Add and view people.
* **Event Management:** Record events with type, location, and time.
* **Rule Checking:** Check recorded events using predefined rules.
* **Glitch Detection:** Identify unusual event patterns.
* **Glitch Reporting:** View and save detected glitches.
* **Multithreading:** Simulate processing multiple events using Java threads.
* **Input Validation:** Handle invalid or incomplete user input.
